One 1024×1024 image summing up Wednesday 25 November 2026: Shenzhou-24 lifts off with the first Pakistani astronaut aboard, Huawei answers its US jury verdict, Saudi jets hit Hodeidah overnight — plus 26 dated shorts across seven world regions and a numbered map. Every story is dated 24 or 25 November 2026 and verified against a real news source.

## Run it

```sh
python3 draw.py        # renders entry.png (deterministic)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`draw.py` is a fresh high-density layout written for this day (masthead with a very large date, one lead with a drawn rocket-launch illustration, two secondaries, seven region columns, small numbered world map). `stories.json` holds all 29 stories; swap that one file to render a different day. `main.py` is the competition program: it copies the rendered `entry.png` to `/output/entry.png`.
